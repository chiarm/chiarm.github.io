Enterprise Buffet — Sistema de gestión de pedidos por QR

Sistema de microservicios para restaurante buffet: los comensales piden por código QR y el personal gestiona cocina, barra y caja en tiempo real. Backend con Spring Cloud (Gateway, Eureka, Config Server), seguridad JWT RSA-2048 con OAuth 2.0 y 2FA, persistencia en PostgreSQL con Flyway, notificaciones en tiempo real por WebSocket STOMP y frontend en Angular 17. Incluye aislamiento multi-tenant con Row-Level Security, trazabilidad con Zipkin, métricas con Prometheus y tests con Testcontainers.

Enterprise Buffet — QR-based order management system

Microservices system for a buffet restaurant: diners order via QR code and staff manage kitchen, bar and cashier in real time. Backend with Spring Cloud (Gateway, Eureka, Config Server), JWT RSA-2048 security with OAuth 2.0 and 2FA, PostgreSQL persistence with Flyway, real-time notifications over STOMP WebSocket, and an Angular 17 frontend. Includes multi-tenant isolation with Row-Level Security, Zipkin tracing, Prometheus metrics, and Testcontainers-based tests.

Java · Spring Boot · Spring Cloud · Angular · PostgreSQL · Docker · WebSocket · Kubernetes
